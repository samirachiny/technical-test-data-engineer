## ⏰ Exécution quotidienne

Ce pipeline est conçu pour être exécuté quotidiennement.  
Voici deux façons de le planifier :

### Sous Linux/macOS :
Ajoutez cette ligne à votre crontab (`crontab -e`) :

0 3 * * * /chemin/vers/venv/bin/python /chemin/vers/src/moovitamix_fastapi/client_pipeline.py


### Sous Windows :
Utilisez le **Planificateur de tâches Windows** :
- Déclencheur : tous les jours à 3h
- Action : `python chemin\\vers\\client_pipeline.py`
